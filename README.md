# mk-studio-web

Aplicação Web Mobile-First do **MK STUDIO** construída em **React + TypeScript + Vite + Tailwind CSS**.

## Pré-requisitos
- Node.js 20+
- API `mk-studio-api` rodando em `http://localhost:8080`

## Como rodar localmente

```bash
npm install
npm run dev
```

A aplicação ficará disponível em `http://localhost:5173`.

Para apontar para outra URL da API ou definir o WhatsApp do estúdio, crie um arquivo `.env` a partir de `.env.example`.
